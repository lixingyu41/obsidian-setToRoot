# Set to Root

语言：[English](README.md) | 中文

在 Obsidian 中打开额外的文件管理器标签页，并将它的根目录设置为指定文件夹。

仅支持桌面端。

## 功能

- 在 Obsidian 默认文件管理器的文件夹右键菜单中添加 `设置为根目录`。
- 打开独立的根目录文件管理器视图，不改变 Obsidian 原本的全库文件管理器。
- 支持复用单个根目录视图，也支持同时打开多个根目录视图。
- 重启 Obsidian 后恢复已打开的根目录视图。
- 支持从可搜索的图标选择器中设置根目录视图的标签页图标。

## 使用方式

1. 打开 Obsidian 默认文件管理器。
2. 右键点击一个文件夹。
3. 选择 `设置为根目录`。
4. 在新打开的根目录文件管理器标签页中浏览该文件夹。

## 设置项

- `根目录视图数量`
  - `只保留一个视图`：复用同一个根目录视图，并替换它的根目录。
  - `允许多个视图`：可以同时打开多个根目录视图。
- `根目录视图图标`
  - 设置根目录视图标签页使用的图标。
